เครื่องปรับอากาศตั้งอุณหภูมิไว้ที่ 25°C ห้องร้อนขึ้นเป็น 28°C เครื่องทำงานหนักขึ้นจนอุณหภูมิลดกลับมาใกล้ 25°C แล้วเครื่องก็ผ่อนแรงลง — ไม่ว่าอุณหภูมิภายนอกจะแกว่งแค่ไหน ห้องก็มักจะถูกดึงกลับเข้าใกล้ 25°C เสมอ นี่คือตัวอย่างที่ชัดที่สุดของ **Balancing Loop** วงจรป้อนกลับที่ทำหน้าที่**ต้านทาน**การเปลี่ยนแปลง ดึงระบบกลับเข้าสู่เป้าหมายหรือจุดสมดุลเดิม

## โครงสร้างของ Balancing Loop

Balancing Loop (เขียนย่อว่า **B**) มีโครงสร้างสามส่วนเสมอ: **สถานะปัจจุบัน** → **ช่องว่างเทียบกับเป้าหมาย (gap)** → **การกระทำที่ลดช่องว่างนั้น** → ย้อนกลับไปแก้สถานะปัจจุบัน วนซ้ำจนช่องว่างเข้าใกล้ศูนย์

ตัวอย่างซอฟต์แวร์ที่เจอบ่อยที่สุด: **Autoscaling** ที่พยายามรักษา CPU utilization ให้อยู่ที่เป้าหมาย (เช่น 60%)

## ทำไม Balancing Loop ถึงสำคัญ — มันคือกลไกของ "ความมั่นคง"

ระบบที่ทำงานได้อย่างมั่นคงต่อเนื่อง (ไม่ระเบิด ไม่ล่มสลาย) เกือบทั้งหมดมี balancing loop ทำงานอยู่เบื้องหลังไม่ทางใดก็ทางหนึ่ง:

- **Rate limiter** — request เยอะเกิน → ปฏิเสธ/ดีเลย์บางส่วน → load กลับมาอยู่ในระดับที่รับไหว
- **Circuit breaker** — error rate สูง → ตัดการเรียก downstream ชั่วคราว → downstream มีเวลาฟื้นตัว → error rate ลดลง
- **Budget การเงินของบริษัท** — ค่าใช้จ่ายเกินงบ → ฝ่ายการเงินเบรกการอนุมัติ → ค่าใช้จ่ายกลับมาอยู่ในกรอบ
- **Performance review รายไตรมาส** — ผลงานต่ำกว่าเป้า → ได้ feedback/coaching → ผลงานขยับกลับเข้าใกล้เป้า

จุดร่วมของทั้งหมดนี้คือ **มีเป้าหมาย (goal) ที่ระบบพยายามรักษาไว้เสมอ** ต่างจาก reinforcing loop (โมดูลถัดไป) ที่ไม่มีเป้าหมาย มีแต่การขยายตัวไปเรื่อยๆ ไม่มีที่สิ้นสุดในตัวมันเอง

## Balancing Loop ที่ "แรงเกินไป" ก็เป็นปัญหาได้

<mark class="hl-warning">ข้อควรระวังคือ balancing loop ที่แรงเกินไปหรือมี delay มาก จะไม่ดึงเข้าสู่เป้าหมายอย่างนุ่มนวล แต่จะแกว่งไปมาเกินเป้าซ้ำแล้วซ้ำเล่า</mark> — เหมือนฝักบัวน้ำอุ่นที่ร้อนไปเย็นไปสลับกันในตัวอย่างเปิดเรื่องของหัวข้อ Delay ก่อนหน้า พฤติกรรมแบบนี้เรียกว่า **oscillation** ซึ่งจะพูดถึงแบบเจาะลึกในโมดูล Behavior Patterns ถัดไป — สิ่งที่ต้องจำไว้ตอนนี้คือ **balancing loop ไม่ได้แปลว่าระบบจะนิ่งเสมอ** มันแค่แปลว่าระบบมีแรงดึงกลับเข้าเป้าหมายอยู่ ส่วนจะนิ่งสนิทหรือแกว่งไปมา ขึ้นอยู่กับความแรงของ loop และ delay ที่ซ้อนอยู่ในนั้นด้วย

โมดูลถัดไปในหัวข้อนี้จะพาไปดูฝั่งตรงข้าม — **Reinforcing Loop** — วงจรที่ไม่มีเป้าหมาย มีแต่การเร่งตัวเองไปเรื่อยๆ ทั้งด้านบวกและด้านลบ
