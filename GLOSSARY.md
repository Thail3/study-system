# Study System

A personal, Thai-language learning site for software architecture and related engineering topics. Content is organised into curricula, chapters and lessons; readers move through them in any order.

## Language

**Track**:
A curriculum on one subject (System Design, System Architecture, Systems Thinking, DevOps & Observability, Source Control, Low-Level Design).
_Avoid_: Course, pillar, section

**Module**:
One chapter of a Track, made of several Topics read on a single page.
_Avoid_: Chapter, unit, pillar

**Topic**:
One lesson inside a Module, authored as a single markdown file.
_Avoid_: Lesson, article, หัวข้อ (in English discussion)

**Case Studies**:
The closing Module of each Track, applying that Track's ideas to realistic scenarios. Every Track has one, so the title alone is ambiguous; refer to a specific one by its slug (e.g. `architecture-case-studies`).
_Avoid_: Capstone
